# 0001 — 务实的最小基础

状态：采用。适用范围：当前最小后端与仓库；不是整个平台的上线批准。

## 决定

1. **按功能依赖核验，不设全局全 SV 门槛。** 与 NewAPI 无关的健康探针、构建和文档可以先做；来源核验与行为测试在依赖它们的 Adapter、身份、资产或迁移功能开始前完成。源码阅读、镜像标签和部分实测各自保留原有证明范围。
2. **一个进程、一个模块。** 采用根模块 `github.com/cy4268/momiao` 与 `cmd/momiao`。暂不创建空 Poker 服务、空前端、Go workspace、未使用的包或目录。需要第二个实际运行时再建立隔离边界；不把将来的 Poker 业务混入当前健康检查。
3. **以工具实际可用性为准。** 不照抄历史版本表。当前 Go `1.27.1` 已对照[官方下载元数据](https://go.dev/dl/?mode=json)及[发行记录](https://go.dev/doc/devel/release)核验；只使用标准库，无 `go.sum` 是因为没有外部模块。后续工具或依赖首次需要时再核验、锁定并测试，不预装整套前端或数据库工具链。
4. **原生命令替代流程负担。** 直接使用 `go vet`、`go test`、`go build`，不要求 Make。CI 只测试与构建；完整 Release Manifest、SBOM、容器、生产配置和迁移校验在确有发布对象时补齐，不用空文件假装完成。
5. **只承诺已运行的接口。** OpenAPI 只描述当前存活探针，没有假的身份接口、业务页面或未验证的外部 endpoint/schema。

## 保留的约束

- 真实鉴权、凭据隔离、Session 行为、数据完整性与迁移证据仍是相应功能的必需条件；不以“先跑起来”省略。
- NewAPI 保持外部独立，当前没有 HTTP/数据库访问、源码 vendoring 或替换已有服务。
- 生产迁移仍需一致快照、恢复演练、幂等与失败测试。真实生产数据、Secret 与原始操作证据不进入 Git。
- 奖励数值、资产规则与 Bright Moonlit / 平面按钮等视觉意图暂不变更；此次没有引入图片或前端实现。

本记录覆盖历史 IS-01 的全量目录、双 Go Module、工具版本表直接照搬及与当前功能无关的全局流程要求；对应树、模块身份、完整验收项和发布产物仅保留为历史规划。其他业务含义不因此自动变更。
