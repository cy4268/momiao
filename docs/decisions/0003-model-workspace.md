# 0003 — 先连通模型、测试与记录

状态：采用。

在可登录门户上增加一个完整的文字调用闭环，不启动全量数据迁移，也不扩成多模态客户端或供应商控制台。

- 模型来源为原生账号可用组及该组的启用模型。列表里的模型表示已配置，不是实时可用性承诺；健康、价格和上下文窗口不靠名称猜测。
- 在线测试使用原生 `/pg/chat/completions` 登录态接口，不创建额外永久密钥。单轮文字、可停止的流式响应、实际用量与消费日志构成验收闭环。刷新和离开页面会清除本页对话；上游可能保留内容，不作零留存承诺。
- 用户明确可见的输出 token 限额是测试预算，不是供应商能力。取消、断流或超时不保证上游未计费，也不会自动重发。
- 渠道管理只实现基本 OpenAI 兼容配置及原生启停。窄字段更新保留既有密钥和高级配置；浏览器角色限制用于界面组织，真正权限继续由原生后端裁定。
- 上游网络独立于门户。门户没有任意 URL 代理功能；实际部署可以只开放一条经过验证的固定目的地传输，不必把私有数据库或应用端口暴露到公网。
- 可以单独复用一个已存在的上游配置及其原生计量设置来验收，不复制旧站用户、密钥集合、账本或历史数据。原生计量设置不代表新平台已经实现定价或充值。

多轮会话持久化、文件/图片/音频、工具调用、完整供应商编辑、价格运营和压测依然独立实施。既有设计归档继续表达长期方向，不作为已交付清单。
