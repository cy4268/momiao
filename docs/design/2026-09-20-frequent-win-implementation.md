# Momiao：获批概率方案的本地实现

日期：2026-09-20。状态：**源码实现与定向验证完成；运行状态由部署环境单独核验。**

本记录对应用户在重新核算后批准的方案，取代旧设计中的实施候选。没有采用先抽输赢档位、再挑选预设老虎机盘面的方案，也没有增加按用户、余额、输赢记录改变结果的开关。

## 1. 最终参数与机制

总派彩包含本金；净赢指总派彩大于本次总下注。

| 游戏 | 单次净赢 | RTP | 最高总派彩 |
|---|---:|---:|---:|
| 老虎机关联的完整十线旋转 | 4565/8192，55.72509765625% | 19181593/16777216，114.33120369911194% | 总下注的 520.1 倍 |
| 刮刮乐一张 | 40% | 107.41% | 总下注的 100 倍 |
| 召唤单抽 | 40% | 109.25% | 单抽下注的 100 倍 |

老虎机仍使用五个独立均匀的 32 停点卷轴、原十条中奖线、从左到右至少三连、Wild 替代、每线仅取最高解释。每轴的一个 L2、L3、H2 改为 L1，共 15 个位置；奖表只改 L1 三/四/五连为 11/12/15、L2/L3 三连为 11，共 5 个数字。其余规则与抽样不变。最低中奖线支付 11 倍线注（1.1 倍总下注），所以新配置不存在“部分返还却算赢”。无中奖线仍然亏掉当次下注。

Wild 五连仍为 5000 倍**线注**，其位置和概率不变：10/33554432；不是 5000 倍总下注。H2 频率降低，L1 四/五连奖额降低。全盘最高奖 520.1 倍总下注的概率为 1/33554432。

原倍率档保持不变，新的整数权重如下（各合计 100000）：

- 刮刮乐：倍率 `[0,1,2,3,5,10,25,100]`；权重 `[40000,20000,37330,2000,500,100,50,20]`。
- 召唤：倍率 `[0,1,2,5,20,100]`；权重 `[40000,20000,39000,850,100,50]`。
- 两者均为净赢/回本/净输 40%/20%/40%；召唤十连仍是十次独立抽样，后台另按整轮总成本展示精确卷积分布。
- 骰子、21 点、德州扑克等多人游戏的规则与结算未改变。

这些是长期数学指标，不是每局、每个玩家或有限本金一定盈利的保证；老虎机期望新增筹码约占累计下注 14.33%。有限本金仍有耗尽下注能力的可能。

## 2. 实现边界

- `slot.FrequentConfig` / `SpinFrequent` / `ResolveFrequent` 复用原真实盘面判奖引擎；规则/卷轴/奖表分别为 `slot-rules-v3` / `slot-strips-v2` / `slot-paytable-v3`。
- 旧 `FrozenConfig`、`FairConfig` 与旧版本配置哈希保持原值，历史回放按每局规则路由。
- 新局金额上界使用 5201 线倍率，旧局保留 5164 上界；新配置的额外检查发生在随机采样之前。
- `0036_frequent_win_games.sql` 新建冻结配置和绑定的 VERIFIED 工件，保留旧配置、旧局、旧工件与已有草稿。版本号使用各游戏当前最大值加一，不占用可能已经存在的版本 3。
- 迁移只切换老虎机、刮刮乐、召唤的新局配置，并作废其未使用的 AVAILABLE 承诺；已创建局使用旧快照复算。
- 只读统计按配置版本 ID、哈希、规则和算法匹配。克隆相同配置时，验证摘要重绑定实际配置身份，不遗留另一版本的 ID/哈希。
- 玩家页面移除概率统计，保留实际规则、奖表和复算。运营工作台 → 游戏 → 选择游戏/配置 → **只读概率详情** 显示精确分数或带方法说明的参考策略样本，不新增胜率开关。
- 21 点的参考工件未包含净赢率，后台明确标记“未包含”，不从 RTP 推造胜率。
