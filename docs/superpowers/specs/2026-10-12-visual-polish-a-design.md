# 视觉 A：统一导航、按钮规范与文案清理

日期：2026-10-12
分支：`codex/visual-polish-a`（基于 main `6d1b273`）

## 背景

用户反馈：按钮突兀；页面上有大量不明所以的编号和"原生登录身份"一类内部字样；切换页面时导航栏和左侧 CHALDEA 标志一直在变；游戏结算时页面闪一下。

本设计是"方案 A"：建立统一规范并清理文案，**不重排页面布局、不改插画、不改后端**。布局重排（方案 B）视 A 的效果再定。

## 已确定的决定

| 项目 | 决定 |
|---|---|
| 术语 | 保留英文风味：保留 Reserve、Master；删除"原生"、短 ID、UUID 等纯技术信息 |
| 按钮 | 方案 1"金线克制"：实心柔金主按钮 + 金色细边次按钮 + 金色文字链接 |
| 英文小标题 | 每页只保留页面大标题上方一行短英文，删除路径前缀和区块级英文 |
| 首页 | 保持浅色与广喜娘 Live2D，仅按钮换新规范 |
| 筹码数字 | 只显示整数，向下取整；悬停 `title` 显示完整数值 |

## 0. 结算闪烁（已完成，提交 `fceba1b`）

根因两处，均已线上逐帧实测确认：

1. `Games.tsx` 在骰子翻滚期间卸载结算卡、落定后重新挂载（155px 区块移出再插回）。
2. 基础浅色主题 `.round-receipt.result-LOSS` 覆盖了沙龙深色样式，输局卡在深色页上是米白色（实测 `rgb(251,248,246)`），骰子、刮刮乐、召唤均受影响。

修复：`RoundReceipt` 新增 `concealed`，同一 DOM 节点保持挂载，仅内容淡出并显示"落定中…"；沙龙三游戏所有结果类型统一深色。回归测试断言翻滚期间节点不变且不提前揭示结果。

## 1. 统一导航栏

### 现状（2026-10-12 线上实测，1280 宽）

| 页面 | 高度 | 标志 | 菜单首项与位置 | 右侧 |
|---|---|---|---|---|
| /dashboard | 68 | CHALDEA PLATFORM（175） | 指挥台@229 | 资产 + 头像菜单 |
| /games | 65 | CHALDEA MOMIAO（224） | 首页@534 | 个人中心按钮 |
| /models | 73 | CHALDEA PLATFORM（185） | 首页@241 | 个人中心按钮 |
| /rankings | 88 | CHALDEA PLATFORM（185） | 指挥台@245 | 资产 + 个人中心 |
| /announcements | 76 | CHALDEA PLATFORM（179） | 模型目录@984，指挥台在末尾 | 无 |

原因：`App.tsx` Shell、`Games.tsx` GamesCatalog、`Catalog.tsx`、`rankings/Rankings.tsx`、`Announcements.tsx` 各自手写一份导航。另外 GamesCatalog 在会话就绪前显示"登录账户"，就绪后变为"个人中心"。

### 设计

- 新组件 `SiteHeader`（新文件 `web/src/SiteHeader.tsx` + `site-header.css`），由上述五处统一调用，删除各自的导航 JSX 与导航 CSS。
- 固定高度 68px（移动端沿用现有 `mobile-nav` 底部导航，不新增）；标志统一为 `Brand`（徽章 + CHALDEA PLATFORM）。
- 登录后菜单：指挥台 · 模型目录 · 娱乐 · 排行榜 · 公告；右侧"资产"+ 头像菜单（沿用 Shell 现有菜单逻辑，抽入组件）。
- 未登录菜单：首页 · 模型目录 · 娱乐 · 排行榜 · 公告；右侧"登录"。
- 会话未就绪：右侧渲染与头像菜单等宽的占位，不显示任何登录态文字。
- 当前页：由路径前缀判定（`/dashboard`、`/models`、`/games|/entertainment`、`/rankings`、`/announcements`），统一金色下划线，`aria-current="page"`。
- 首页 `/` 不使用 `SiteHeader`，保持现状。
- 头像菜单移除"原生登录身份"一行；按钮下方小字由"Master 身份"改为角色名（如"管理员"）或省略。

## 2. 按钮规范

在 `styles.css` 定义设计变量与三种样式，作为全站唯一来源：

```css
:root {
  --gold: #d9bf86; --gold-line: #d9bf8666; --ink-on-gold: #14243a;
  --text-strong: #f0dcae; --text-body: #e8dcc2; --text-soft: #c0d0e4;
  --control-h: 40px; --control-radius: 4px;
}
```

| 类型 | 选择器 | 外观 |
|---|---|---|
| 主按钮 | `.primary`（及映射：`.game-play`、`.extra-primary`、`.pk-primary`） | 实心 `--gold`，字 `--ink-on-gold` |
| 次按钮 | `button`、`.button` 默认 | 透明底，1px `--gold-line` 边，字 `--text-body` |
| 文字链接 | `a`（非按钮） | 字 `--gold`，悬停下划线 |

- 高度 `--control-h`（≤720px 宽为 44px），圆角 `--control-radius`，字号 14px，悬停/禁用/焦点态统一定义一次。
- 删除各页面 CSS 中按钮的 `background / border / color / border-radius / height / box-shadow / font` 声明，仅保留布局（margin、flex、width、grid）。涉及约 30 个文件，**排除 `ops/`**。
- 每屏至多一个主按钮：游戏页为开局按钮；指挥台为"选择模型并接入"；其他页面按需。
- 文案：移除按钮与链接中的"→"，外部链接保留"↗"。

## 3. 文案清理

| 位置 | 现状 | 改为 |
|---|---|---|
| 全站 | 原生额度 / 原生单位 / 原生可用 | API 额度（单位文字删除） |
| 指挥台底部、个人中心、头像菜单 | 原生登录身份：墨恒 · dc_… | 删除 |
| 指挥台、个人中心 | 账户短 ID：CA-… · 仅本人可见 | 删除 |
| 账户与安全 | 登录身份 | 保留，标为"登录名""账户编号"（客服核对用） |
| 钱包交易列表 | 每行完整 UUID | 删除；交易详情页保留 |
| 钱包 | "与原生额度独立""Reserve + Active""最小步长 0.000002" | 每页最多一处说明；删除 Active 拆分与步长提示 |
| 筹码余额（钱包、游戏页、结算卡） | 6,270.37079 | 6,270（向下取整，`title` 显示完整值） |
| 英文小标题（113 处） | CHALDEA / COMMAND CENTER 等 | 每页仅大标题上方一行（如 COMMAND CENTER） |
| 结算卡经济回执行 | 原规则派彩 0 / 实际到账 0 / 封顶未入账 0 | 仅本局实际触发封顶时显示 |

"规则版本""Server Seed Hash"等仅在规则/公平验证弹窗内出现的信息保留（属于可验证性功能）。

筹码取整只影响显示：下注输入、校验、提交仍使用精确值；"可用筹码不足"等判断不变。

## 4. 文字与对比度

- 字号阶梯：标题沿用现状；正文 ≥13px；说明文字 ≥12px（替换现有 11px）。
- 深色底次要文字统一用 `--text-soft`（#c0d0e4，在 #0e2339 上对比度约 10:1），替换各处低对比灰蓝。

## 不在范围内

- `/ops` 运营后台；页面布局与立绘位置；首页配色；后端、数据库、游戏规则与概率。

## 发布

- 登录后页面无法本地预览（内置浏览器不能访问本机服务，登录态绑定 momiao.win），以线上验证为准。
